
# Robot Speech-Synthesis Mimic Using a Servo Motor

## Project Overview

A robotics-related project involving a speech-synthesis mimic and a servo motor.

## Components and Technologies

- Servo motor: SG90
- Controller: Arduino Uno
- Programming language/software: C++
- Other components: OLED screen, Aux Cable, Transistors, Resistors

## How It Works

Basically tries to mimic Human speech using servo motors based on the audio input it gets.
